> See `memory/constitution.md` for the full, canonical constitution.

## Core Principles

### I. Spec-Driven Development
Every code change traces to a ticket and spec. No skipping the workflow: Specify → Plan → Implement → Review.

### II. Agent Separation
Claude is the sole code author. Codex is the sole reviewer. Neither crosses into the other's domain.

### III. Tests Are Mandatory
TDD enforced. Every feature must have tests. No merging without passing tests.

### IV. Security First
Never commit secrets. Validate all inputs. No injection vulnerabilities.

### V. Simplicity
Start simple, YAGNI principles. Prefer clarity over cleverness.

## Governance
Constitution supersedes all other practices. See `memory/constitution.md` for full details.
